# Offensive Security

Repositório dedicado aos meus estudos e laboratórios de segurança ofensiva.

Os projetos envolvem exploração de ambientes Active Directory e aplicações Web, com foco na compreensão de vulnerabilidades, técnicas de ataque e caminhos de comprometimento.

## Conteúdo

- **Active Directory** — Laboratórios envolvendo enumeração, exploração de permissões, credenciais e diferentes técnicas utilizadas em ambientes Windows/AD.
- **Web Security** — Laboratórios envolvendo identificação e exploração de vulnerabilidades em aplicações Web.

Cada projeto possui sua própria documentação com detalhes sobre a metodologia, técnicas utilizadas e resultados obtidos.
